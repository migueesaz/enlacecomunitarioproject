Proyecto para la Gestion de informacion Consejo Comunal La Cruz

Boton de Reset Password
Ver Poblacion(Ver personas registradas, Editar registro, eliminar)
Gestion de Cartas (Ver, Aprobar, Rechazar, Imprimir)

Notificaciones(crear, Ver, Editar, Fecha Evento)

Ver Mensajes
Solicitud de Cartas: (Residencia, Buena Conducta, Aval)
